# Professor Izidor Gertner: Research, Student Work, and Project Directions

## Scope

This note concerns Professor Izidor (also listed as Isidor) Gertner of The City
College of New York. It does not claim that all 100 projects below were built by
Professor Gertner. Public sources do not provide a verified list of 100 projects.
The list is a set of original project directions grounded in his documented
research, publications, courses, and capstone topics.

The student-work catalog uses two labels:

- **Named**: a public source identifies the work, student or team, and Gertner's
  supervisory, instructional, or collaborative connection.
- **Assigned**: a public course archive identifies the implementation as work
  assigned in one of Gertner's courses. These are project artifacts and labs,
  not claims of 100 separately named capstone teams.

## Best Fit for CustomCPU

The strongest immediate sequence is 62, 61, 63, 64, 75, 68, 69, 66, 72, and
60. It preserves the CPU-learning goal while creating the hardware/software path
needed for a serious TinyML or target-recognition system.
